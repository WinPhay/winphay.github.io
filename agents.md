## Portfolio Systems

1. **Vessel (`v0.6.0`)** — `https://github.com/WinPhay/vessel`
   Containerized execution shield for coding agents with sub-second filesystem checkpoints, Myers delta diffs, DLP redaction, headless Chromium inspection, and git worktree isolation.
2. **Auralis (`v0.2.1`)** — `https://github.com/Celestrionx/auralis`
   Headless Rust audio graph compiler and closed-loop auditory telemetry engine with stdio MCP server (`auralis_init_manifest`, `auralis_compile_audio`, `auralis_inspect_soundfont`, `auralis_eval_wav`).
3. **StellarPub (`Live`)** — `https://stellarpub.celestrionx.com`
   Digital publishing platform for Burmese literature and OTA `.pck` packages.
